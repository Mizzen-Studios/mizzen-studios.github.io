PlanDesk documentation

Requirements and setup

An authorized Jira site administrator and suitable Jira Service Management access are required. PlanDesk does not grant seats, native request visibility or customer permissions. Once an approved installation is available, open PlanDesk in the project sidebar. An administrator can expand Map settings, supply an authorized level image, import and position rooms, bind the intended project/portal/request type and save. Configure only a currently available intended workflow transition; no native workflow/form changes are automatic.

Report location

On the existing request form, select or search for the mapped room. A selection is staged; it does not itself submit a request. Submit through the native Jira Service Management form.

Find and complete work

Work by room shows a bounded search of native-visible mapped requests, separated into open and completed work. Truncation and unverified-location warnings mean it is not an exhaustive site register. Inspect the saved plan with zoom and scrolling. An eligible authorized user can upload/select an after-photo and finish through an available configured transition. Native request/participant/organization/attachment access remains authoritative.

Photos and plans

Use only authorized content. Remove sensitive details and EXIF/GPS metadata before upload: small images can retain metadata. A shared plan can expose printed room labels even when room records are filtered. A clearly marked illustrative demo photo is not repair evidence.

Current limits

No offline mode, Assets integration, Realtime feed, complete per-group/per-portal visibility policies, automated contractor invitations or guaranteed arbitrary-customer access. Fresh-site and real customer-isolation acceptance are release gates, not proven by a deployment or demo. Configure and test native sharing before inviting customers.

Removal

An administrator can uninstall through Atlassian. Jira records/attachments/properties and platform-retained data may remain. Uninstall is not immediate complete erasure. Ask your site administrator and Mizzen Studios about an authorized data request.
